## インストール

### 必要なもの

- macOS 11.0以降
- Logic Pro 10.7以降
- Xcode Command Line Tools
- CMake（自動インストール可能）

### ビルド手順

```bash
cd Real Tune
./build.sh
```

ビルドスクリプトが自動的に：
1. 依存関係をチェック
2. プロジェクトをビルド
3. プラグインをインストール
4. Audio Component Registrarをリセット

### 手動インストール

ビルドされたプラグインは以下の場所にインストールされます：

```
~/Library/Audio/Plug-Ins/Components/Real Tune.component
```

## 基本的な使い方

### 1. Logic Proでプラグインを追加

1. オーディオトラックを選択
2. インサートスロットをクリック
3. **Audio Units → Real Tune** を選択
4. プラグインウィンドウが開きます

### 2. 基本設定

#### ボーカル録音の場合

1. **Key**: 曲のキーを設定（例：C）
2. **Scale**: Major または Minor を選択
3. **Retune Speed**: 50-70% から開始
4. **Mix**: 100% で完全なオートチューン効果

#### 楽器録音の場合

1. **Scale**: Chromatic を推奨
2. **Retune Speed**: 30-50% で自然な補正
3. **Mix**: 70-90% で元の音色を保持

## パラメータ詳細

### Retune Speed（リチューン速度）

**範囲**: 0-100%

- **0%**: ピッチ補正なし（バイパス）
- **1-30%**: 非常に自然な補正（微調整）
- **30-70%**: 標準的な補正（ボーカル録音に最適）
- **70-90%**: 強めの補正（T-Pain効果の始まり）
- **90-100%**: 極端な補正（ロボット声、T-Pain効果）

**使用例**：
- アコースティックボーカル: 30-50%
- ポップスボーカル: 50-70%
- ヒップホップ/R&B: 80-100%

### Key（キー）

**範囲**: C, C#, D, D#, E, F, F#, G, G#, A, A#, B

曲のキーに合わせて選択します。キーが不明な場合は：
1. Chromatic スケールを使用
2. または Logic Pro のキー検出機能を使用

### Scale（スケール）

- **Major（メジャー）**: 明るい雰囲気の曲
- **Minor（マイナー）**: 暗い雰囲気の曲
- **Chromatic（クロマティック）**: 全ての音を補正（ジャズ、複雑な旋律に最適）

**音階の違い**：
- Major: ド・レ・ミ・ファ・ソ・ラ・シ
- Minor: ラ・シ・ド・レ・ミ・ファ・ソ
- Chromatic: すべての半音（12音）

### Mix（ミックス）

**範囲**: 0-100%

- **0%**: 完全にドライ（原音のみ）
- **50%**: 50/50ミックス
- **100%**: 完全にウェット（処理音のみ）

**推奨設定**：
- 自然な補正: 60-80%
- 明確な効果: 90-100%
- 微妙な補正: 40-60%

### Formant Preserve（フォルマント保存）

**範囲**: 0-100%

フォルマント（音色の特徴）をどれだけ保存するか：
- **100%**: 自然な音色を完全に保持
- **50%**: バランスの取れた処理
- **0%**: ピッチシフトのみ（音色変化あり）

**注意**: 通常は80-100%を推奨

## 使用例

### 例1: ポップスボーカルの自然な補正

```
Retune Speed: 55%
Key: G
Scale: Major
Mix: 85%
Formant Preserve: 90%
```

**効果**: 明確だが自然なピッチ補正。プロフェッショナルな仕上がり。

### 例2: ヒップホップ/R&Bのオートチューン効果

```
Retune Speed: 95%
Key: D
Scale: Minor
Mix: 100%
Formant Preserve: 85%
```

**効果**: T-Pain/Travis Scott風の明確なオートチューン効果。

### 例3: アコースティックの微調整

```
Retune Speed: 35%
Key: C
Scale: Major
Mix: 60%
Formant Preserve: 95%
```

**効果**: 非常に自然で、ほぼ気付かれないピッチ補正。

### 例4: 実験的/ロボット声

```
Retune Speed: 100%
Key: E
Scale: Chromatic
Mix: 100%
Formant Preserve: 70%
```

**効果**: 極端なオートチューン効果。エレクトロニック音楽に最適。

## 実践的なヒント

### 1. レイテンシーについて

Real Tuneは低レイテンシー設計（約11ms @ 44.1kHz）：
- リアルタイム録音に対応
- モニタリング時の遅延が最小限
- ライブパフォーマンスにも使用可能

### 2. CPU使用率の最適化

- 不要なトラックでは無効化
- バウンス時は高品質設定を使用
- リアルタイム録音時は標準設定を使用

### 3. 他のエフェクトとの組み合わせ

**推奨シグナルチェーン**：

```
1. EQ (ハイパスフィルター)
2. Compressor (軽く)
3. Real Tune ← ここ
4. De-esser
5. Reverb/Delay
```

**理由**：
- EQ前処理で不要な低音を除去
- コンプレッサーで音量を均一化
- Real Tuneでピッチを補正
- 後処理でサウンドを完成

### 4. マイクテクニック

オートチューンの効果を最大限に：
- 安定した音量で歌う
- マイクとの距離を一定に保つ
- ポップフィルターを使用
- 適切なゲイン設定

## トラブルシューティング

### 問題: プラグインが Logic Pro に表示されない

**解決策**：
1. Audio Component Registrarをリセット：
   ```bash
   killall -9 AudioComponentRegistrar
   ```
2. Logic Proを再起動
3. プラグインマネージャーで確認：
   - Logic Pro → 環境設定 → プラグインマネージャー
   - Real Tuneが有効か確認

### 問題: 音が歪む・クリッピングする

**解決策**：
- 入力ゲインを下げる
- Mix設定を下げる
- コンプレッサーを前段に追加

### 問題: ピッチ検出が不安定

**原因と解決策**：
- **背景ノイズが多い**: ノイズゲートを使用
- **音量が小さい**: 入力ゲインを上げる
- **複数の音が混在**: ソロトラックで使用
- **極端に高い/低い音**: 対応周波数範囲（80-1000Hz）を確認

### 問題: 不自然な音になる

**解決策**：
- Retune Speedを下げる（30-50%）
- Mixを下げる（60-80%）
- Formant Preserveを上げる（90-100%）
- 正しいKey/Scaleを設定

### 問題: レイテンシーが気になる

**解決策**：
- Logic Proのバッファサイズを小さく設定
  - 環境設定 → オーディオ → I/Oバッファサイズ
  - 128サンプル以下を推奨
- 低レイテンシーモードを有効化

### 問題: ビルドが失敗する

**チェック項目**：
1. Xcodeがインストールされているか
   ```bash
   xcode-select --install
   ```
2. CMakeがインストールされているか
   ```bash
   brew install cmake
   ```
3. macOSバージョンが11.0以降か

## 高度な使用法

### オートメーション

Logic Proでパラメータをオートメーション可能：
1. トラックでオートメーションを有効化
2. Real Tuneのパラメータを選択

## パフォーマンスベンチマーク

## よくある質問（FAQ）

**Q: 無料ですか？**
A: はい、完全無料でオープンソースです（MIT License）。

**Q: 商用利用できますか？**
A: はい、ライセンスの範囲内で自由に使用できます。

**Q: Logic Pro以外でも使えますか？**
A: Audio Unit V3対応のDAWで使用可能（GarageBand、Abletonなど）。

**Q: Windowsで使えますか？**
A: いいえ、macOS専用です。WindowsではVSTプラグインとして再実装が必要です。

**Q: リアルタイムで使えますか？**
A: はい、低レイテンシー設計でリアルタイムレコーディングに対応しています。

**Q: 他の有料オートチューンと比べてどうですか？**
A: 基本的なピッチ補正機能は同等です。高度な機能（グラフィカルエディタなど）はありません。
