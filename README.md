# SVQRA

**SVQRA** is a customized AI interface rebuilt from Open WebUI, fully rebranded and optimized for personal high-performance usage.

---

## 🔰 Features

- Gemini 2.5 Pro, Claude 3, GPT-4o integration
- Removed all Open WebUI branding
- Local & Vercel support (fully portable)
- Token self-management
- High-speed & lightweight front-end

---

## 🛠 Local Setup

```bash
pip install open-webui
open-webui
```

Access:
```
http://localhost:3000
```

---

## 🚀 Vercel Deployment

1. Fork or clone repository  
2. Rename `vercel.json` project field to:
```json
{
  "project": "svqra"
}
```
3. Push to GitHub  
4. Import repo into [vercel.com](https://vercel.com)  
5. Set environment variables if needed
